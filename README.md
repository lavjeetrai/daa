## ✨ About

**LAV Resort** is a beautifully composed, fictional coastal retreat where considered design meets slow living. The page pairs an earthy luxury palette with elegant typography, custom SVG artwork, suites, seasonal stories, and a polished responsive layout.

The project uses `@hyper-elements/react` as a component and rendering system rather than traditional DOM markup.

## 🌊 Highlights

- Responsive resort landing page
- Custom coastal illustration and botanical brand mark
- Editorial typography and refined nature-inspired palette
- Suite listings, resort details, experiences, and seasonal sections
- Static HTML rendering through the Hyper Elements React renderer
- Built with modern Vite, React, and TypeScript tooling

## 🧰 Tech Stack

| Technology | Purpose |
|---|---|
| React 19 | Component architecture |
| TypeScript | Type-safe application code |
| Vite 8 | Development server and production builds |
| `@hyper-elements/react` | UI components and HTML rendering |
| Custom SVG | Resort artwork and logo |

## 🚀 Quick Start

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the local URL printed by Vite.

### 3. Build for production

```bash
npm run build
```

The production bundle will be generated in `dist/`.

### 4. Run TypeScript checks

```bash
npm run typecheck
```

## 📁 Project Structure

```text
.
├── index.html          # Vite entry document
├── src/
│   ├── main.tsx        # Renders the Hyper Elements page into the browser
│   └── index.tsx       # LAV Resort page, components, styles, and artwork
├── package.json        # Scripts and dependencies
├── tsconfig.json       # TypeScript configuration
└── vite.config.ts      # Vite configuration
```

## 🎨 Customize

The main visual system lives in `src/index.tsx`:

- Update resort colors in the `C` palette.
- Change display and body fonts through `SERIF` and `SANS`.
- Replace the custom SVG constants for different artwork.
- Edit suite names, prices, seasons, and navigation labels directly in page components.
